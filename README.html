AI 实践课：从预测到决策的 60 个问题

用 Python 把问题变成可检查的分析、预测、规划与策略。

这套中文课程从一位 AI 研究生的实际需求出发：理论学过不少，却不擅长独立写代码；希望通过临摹完整案例，逐渐学会用 AI 解决问题。课程分为 30 个基础案例 + 30 个进阶案例，先练实现，再练建模、推演和决策。

每个案例有独立文件夹，包含任务说明、中文教学 Notebook、完整脚本、三层练习、参考答案、数据说明、来源和实际输出。案例运行不依赖你完成前一课的作业。

知识值得分享。 欢迎学习、改编、纠错，也欢迎贡献你解决过的具体问题。

快速开始

首版验证平台是 Windows x64、Python 3.12、CPU。大型模型课建议至少16GB内存，一次运行一个模型内核。其他操作系统尚未完成同等验收。

git clone https://github.com/SCUliujiacheng/ai-practical-course.git
cd ai-practical-course
py -3.12 tools/setup_environment.py

安装成功后，双击 开始学习.cmd，进入 01_AI基础课/01_天气CSV统计/教学讲解.ipynb，按 Shift+Enter 逐格运行。无需手动激活虚拟环境。

模型课需要先下载固定版本权重：

.\.venv\Scripts\python.exe tools\prepare_models.py --all

详细步骤、模型选择与报错处理见 安装指南。第一次安装和下载需要互联网；代码、数据和模型准备完成后，核心案例可以离线运行。若只想阅读，下载仓库后打开 课程首页.html，或直接在 GitHub 查看 Notebook。

仓库提供什么

  • 60个完整脚本、180份Notebook、180道补全/修改/迁移练习及答案。
  • 已执行的教学和答案网页、图表与小型结果文件。
  • 有明确来源与许可的天气、短信、单车小数据；模拟输入明确标注。
  • 精确依赖清单、模型固定revision与SHA256、安装与离线准备工具。
  • 基线、独立测试、失败情景、方法边界；进阶课还有决策建议。

虚拟环境、Python运行时、wheel安装包和大型预训练权重由准备工具在本机生成，不存入Git仓库。五套预训练模型约2GB，来源及许可见 第三方说明。联网选修见 联网拓展清单，可以延后学习。

需要去没有网络的地方学习？

先按 离线准备指南 下载依赖、模型和恢复材料，完成自检，并在自己的电脑上关网试运行。GitHub仓库本身不等于已经配置好的离线环境。模型和运行环境备妥后，整目录一起携带。

怎样使用这些案例

先写输入、目标和预期结果，再运行示例；临摹关键步骤后，关闭答案做练习。每五课完成一次迁移挑战。简单方法表现更好时保留它，模型回答错误时核对依据，求解器给出方案时检查现实约束。

首版60课曾在Windows本机完成240项脚本/Notebook运行检查；这是特定环境的记录，不保证在任意环境或真实业务上有效。公开版测试范围见 验收与复现说明。

这是一套 AI辅助编写并经程序执行检查的教学案例库。它依据公开方法重新实现，不冒充企业生产系统或“行业最优方案”。科学问题、模型假设和结果解释仍值得持续审阅，欢迎在Issue中指出问题。
