先准备，再离线使用

GitHub 下载不等于已经取得完整离线包。先依照 安装指南 安装课程环境，下载所需模型，再准备恢复包；这几步需要联网或一份已经完整下载的本地资源。课程运行阶段可断网。

在能联网的 Windows x64 电脑上准备

在课程根目录运行：

py -3.12 tools/setup_environment.py
.venv/Scripts/python.exe tools/prepare_models.py --all
.venv/Scripts/python.exe tools/prepare_offline.py
.venv/Scripts/python.exe tools/self_check.py --full-hash

prepare_offline.py 会复制当前 Python 3.12 的基础运行时到 runtime/python，从指定官方索引下载锁文件的190项wheel到 wheelhouse，使用 --no-index --dry-run --ignore-installed 检查本地依赖解析，最后生成 runtime/offline_manifest.json。复制基础运行时不复制其第三方 Lib/site-packages；依赖由wheel重建。它不移动或修改正在使用的 .venv。

如果 runtime/python 已存在，脚本会复用当前基础运行时本身，或逐文件核对它是否与要复制的基础运行时一致。一致时继续准备wheel；不一致时保留目录并停止，不会覆盖正在使用的运行时。

准备离线恢复包.cmd 提供同样入口。--dry-run 只检查和显示计划，不复制或下载。模型单独由 prepare_models.py 准备，运行时与190个wheel就绪不能代表大模型也已准备。

已有外部 wheelhouse：全程使用本地安装包

例如在U盘上已有同一锁文件对应的190个Windows/Python3.12 wheel：

py -3.12 tools/setup_environment.py --wheelhouse 'E:/course-packages/wheelhouse'
.venv/Scripts/python.exe tools/prepare_offline.py --wheelhouse-source 'E:/course-packages/wheelhouse'

第一条从外部目录安装；第二条将这些wheel复制到课程目录，同时复制当前基础运行时。--wheelhouse 使用 --no-index --no-cache-dir --find-links 和课程离线网络防护，不会在缺包时悄悄回退联网。缺少、版本错误或平台不兼容的wheel会报错。准备程序验证wheel元数据、复制哈希与本地解析；它不把未知来源安装包自动认定为可信来源，应使用自己从官方索引准备的包。

课程内恢复清单记录运行时及每个wheel的SHA256，供以后检测文件缺失或损坏。锁文件锁定版本，但并非自带所有包的上游SHA；第一次下载仍依赖官方HTTPS索引与包分发。模型则使用仓库已记录的原始文件SHA。

复制到另一台电脑或移动文件夹

仅面向已验证目标 Windows x64 / Python 3.12 / CPU。将整个已准备的课程文件夹复制过去，至少保留源码、数据、需要的模型、runtime/python、runtime/offline_manifest.json、wheelhouse和锁文件。运行时许可文件也要保留。

.venv 和 Jupyter 内核含本机绝对路径，不应当作可直接搬动的便携环境。移动目录或换电脑后，关闭所有课程进程，显式重建：

runtime/python/python.exe tools/repair_environment.py --dry-run
runtime/python/python.exe tools/repair_environment.py --rebuild
.venv/Scripts/python.exe tools/self_check.py --full-hash

也可双击 重建离线环境.cmd。重建前先校验恢复清单；验证通过后才把原 .venv 保留为 .venv_backup_时间，再从本地运行时和wheel建立新环境并重新绑定内核。失败会尝试回滚，失败的新环境保留为 .venv_failed_时间 供诊断。无 --rebuild 的普通调用不会移动环境。此流程不下载文件，也不删除备份。

恢复包未准备好时，不要运行重建来“试试看”；先在有网电脑上补齐。macOS、Linux、Windows ARM及不同Python版本不在这份离线包的验证范围内。

确认检查范围

.venv/Scripts/python.exe tools/self_check.py --core --full-hash
.venv/Scripts/python.exe tools/self_check.py --full-hash

前者检查190项依赖、60个案例和小数据，允许尚未下载模型；后者还校验全部模型。--core --assets-only 可用于仅检查小数据/课程文件；单独 --assets-only 仍检查模型，但不证明Python环境或案例执行成功。恢复包准备记录见 reports/offline_preparation.json，重建记录见 reports/repair_validation.json。

准备成功后可断网启动课程。不要把 .venv、runtime、wheelhouse 或权重提交到源码Git仓库；它们是本地准备产物，完整离线拷贝应独立保存。
