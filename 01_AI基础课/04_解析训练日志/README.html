B04 怎样把训练日志自动变成学习曲线？

核心案例：离线可学。 首次先按安装指南配置环境、下载所需模型。准备完成后，输入均从本课程目录读取。外部参考链接不影响本地运行。需要联网的延伸活动见联网拓展清单，可延后学习。

解析文本中的 epoch、训练误差和验证误差；识别未解析行，选择验证误差最低的轮次，并演示过拟合。日志为预设教学样例，不冒充真实训练结果。

先修与运行

B01；字符串、正则命名组、字典列表与图表。

在课程根目录双击「开始学习.cmd」，进入本文件夹并打开教学讲解。也可以双击本目录「运行案例.cmd」。

学习顺序

  1. 阅读任务，写下输入、输出和你预计的结果。
  2. 打开教学讲解，逐格运行，观察变量和图表。
  3. 对照 solution.py 临摹关键步骤。
  4. 完成动手练习的补全、修改与迁移，再看参考答案。
  5. 检查 outputs，解释方案的适用范围。

方法与检查

1. 读取混杂日志

真实日志可能混入警告。先读成逐行文本，不假设每一行都是训练结果；保留行号，解析失败才有位置可找。

2. 正则表达式提取有名字的字段

(?P<epoch>...) 给捕获组命名；浮点模式接受小数与科学计数法。没有匹配的行另外保存，避免“成功运行”掩盖数据漏读。

3. 验证集选择停止点

训练误差下降并不意味着泛化改善。idxmin 返回最小值的行索引，再用 loc 取整行。这里没有测试集，不能把最小验证误差当最终测试表现。

4. 保存供复核的结构化结果

同时交付曲线、解析表和未解析行，便于分清格式错误与训练问题。纵轴应标损失而不是准确率。

常见错误与边界

日志是教学预设，不代表模型实测训练；本例实测结果指解析与选轮次的输出。验证集选轮次后仍需要独立测试集。
