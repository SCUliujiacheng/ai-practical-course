## 1. 目标与学习方式

为你建立一套**以实际问题为入口、可以长期临摹和练习的案例库**。按照你已经确认的需求：

- 起点：基础语法能看懂，但独立写代码困难。
- 方向：全面打牢 Python 和 AI 实践基础。
- 节奏：不限定学习周期，按照掌握程度推进。
- 交付：首版包含 **30 个完整案例**，每个都有讲解、代码、数据说明、练习和答案。

统一采用“**理解问题 → 拆解步骤 → 运行案例 → 临摹代码 → 修改条件 → 独立迁移**”的学习过程。Python 知识随案例引入，每例明确标注需要掌握的语法和函数。

### 实用解法与新方法的安排

- **B07/B10：** 核心各比较两种方法：B07 使用线性回归与梯度提升回归，B10 使用逻辑回归与梯度提升分类；随机森林作为额外对照，TabPFN 等表格基础模型作为小样本拓展。先锁定数据划分、评价预算和版本，再比较，不把榜单成绩视为当前数据上的保证。
- **B15：** 核心完成季节基线、历史特征树模型、滚动预测和区间评价；Chronos、TimesFM 等预训练时序模型作为候选，制作时选择一个满足本地条件的版本完成拓展对照。记录训练语料与公开测试数据可能重叠的未知项，不轻率宣称“全新领域零样本泛化”。
- **B20/B21：** 保留从简单表示到预训练模型的过程；预训练模型必须与较简单的方法比较。微调只在数据、目标与计算成本支持时开展，不作为所有文本问题的默认步骤。
- **B22—B24：** 使用带人工相关性和答案依据标注的小型评测集。B22 学习关键词检索，B23 核心比较关键词与向量检索，混合检索与小候选集重排作为拓展；B24 核心完成一条本地检索问答路径。检索质量、回答事实支持、无答案拒答和运行代价分别报告。人工标注用于发现自动评判遗漏，语言模型评分仅作辅助。
- **模型选型：** 不将某个历史模型写成永久推荐。原计划中的 all-MiniLM-L6-v2、FLAN-T5-small 保留为可复现的轻量对照；中文任务增加经核验的中文适用模型候选。数据集、精度、许可、下载条件与内存评估后，锁定具体模型 ID、权重版本和配置。
- **控制学习负担：** 每例核心只要求一个简单基线和一个有实际价值的解法，扩展比较单列且不阻塞主线；前五例仍聚焦 Python 与数据基础。具体候选以根目录选型记录为准。

## 4. 天气预测案例的具体标准

第 06 例作为第一个完整机器学习项目：

- **任务：** 在一天观测结束后，使用截至当天可获得的数据，预测下一天的最高温度。
- **数据：** 使用公开的 Jena 气象数据，将原始观测整理为日统计，解释字段、单位和处理过程。该数据也用于 [TensorFlow 官方时间序列教程](https://www.tensorflow.org/tutorials/structured_data/time_series)。
- **方法：** 核心比较“明天最高温等于今天”的简单基线与线性模型；随机森林作为完成主线后的额外对照。
- **评估：** 按时间划分训练、验证、测试数据；预处理只在训练数据上拟合，用验证集选择方案，最后评估测试集。
- **成果：** 预测对照表、MAE 误差、真实值与预测值曲线，以及预测较差日期的分析。
- **练习：** 修改历史窗口、增加历史特征、改为预测最低温，并解释改动理由。

案例定位为单站历史数据预测练习，如实呈现效果和局限。

## 5. 运行默认值与交付验收

- **环境：** Windows x64、按安装指南配置的 Python 3.12（原验收为3.12.13）、JupyterLab。最终交付使用课程根目录的一套 `.venv`，统一锁定基础、深度学习、文本模型依赖，减少离线时切错环境的风险；无需另外安装 VS Code。
- **语言：** 全中文讲解；代码使用常见英文命名，英文数据提供字段释义。
- **计算：** 默认提供 CPU 可运行的小数据配置，GPU 加速为可选项。每例记录实测运行时间和资源需求。
- **模型配置：** MiniLM、FLAN-T5-small、Qwen3-0.6B、Chronos-Bolt-tiny、ResNet18 需先按[安装指南](../安装指南.md)下载到课程 `assets/models`，按显式本地路径加载；来源、固定 revision 和许可见仓库记录。需要额外模型、授权或云服务的活动在对应 README 标为联网选修。
- **运行验收：** 30 例的参考脚本、教学 Notebook 和答案均实际执行；Notebook 重启内核后可顺序运行，结果来自真实执行。
- **方法验收：** 检查数据泄漏、时间/分组等划分方式、基线、指标、随机变异、运行代价和失败案例；检索问答额外检查无答案问题、检索失败和引用是否支持回答。区间方法须说明假设，区分预测区间、指标估计区间与经验覆盖率；不能把独立同分布条件下的保证直接套用于时间序列。
- **新方法验收：** 与基线在一致数据与评价预算下比较；未运行或因网络、许可、硬件受限的拓展标为未验证，不能填入假结果或声称已经更好。核心 30 例仍须全部运行通过。
- **学习验收：** 每例都有可检查的成果和三层练习，前期提供详细提示，后期增加独立实现比例，所有阶段保留完整答案。
