方法与检查

1. 把数据变成形状明确的 Tensor

输入 x 是 N×1，目标 y 也是 N×1。保留测试集，只用训练集学习；同形状避免广播偷偷产生 N×N 的损失。Python 的切片用于划分，float32 是本例的计算类型。

2. 从一个导数到网络参数

requires_grad=True 告诉 PyTorch 记录运算。先核对 (w−3)² 在 w=1 的梯度为 −4，再建立 1→24→1 网络；ReLU 提供非线性，参数不是手工指定的答案。

3. 写出每一次更新

zero_grad 清掉上次梯度，backward 计算当前梯度，step 更新参数。缺少清零会累加梯度。每次循环都记录训练损失，但不据测试损失挑选轮数。

4. 在未参与训练的数据上检查

eval 切换推理模式，no_grad 不建立梯度图。把网络与只猜训练均值的基线比较；保存权重时同时保留模型结构。观察拟合曲线比只看最终损失更直观。

常见错误与边界

训练损失小不能证明泛化；不得把测试集用于调轮数。传感器公式是教学假设。
