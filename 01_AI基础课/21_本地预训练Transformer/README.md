## 方法与检查
## 1. 定义任务与规则对照
目标输出只能是 positive 或 negative。测试句含否定，模型只看文本，不看人工标签；词典很便宜，但不知道句法。

## 2. 本地加载与批分词
Tokenizer 将文本变成 token ID；attention_mask=0 表示补齐。FLAN-T5 是编码器—解码器模型，必须使用相应模型类。local_files_only 禁止运行时下载。

## 3. 生成与独立解析
固定贪心解码和最大新 token 数。解析器只接受约定标签，其他文本记为 invalid；格式合法不代表语义正确。

## 4. 保留真实输出与错误
分别报告格式通过率、准确率与耗时。六句仅能说明本例行为，不能代表全部评论；不得通过改测试句掩盖失败。

## 常见错误与边界
微调为拓展；不得用测试标签调提示词。该模型主要用于英文教学对照。
