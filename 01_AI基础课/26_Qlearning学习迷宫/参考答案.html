1. 补全：终止目标

终点奖励 10，旧Q=2，学习率0.2。终止时不得加下一状态价值，更新结果应为3.6。

old = 2.0
reward = 10.0
alpha = 0.2
done = True
next_value = 100.0
target = reward if done else reward + 0.95 * next_value
updated = old + alpha * (target - old)
assert np.isclose(updated, 3.6)
print(updated)
3.6
