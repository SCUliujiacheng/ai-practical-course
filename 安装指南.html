安装课程环境

GitHub 源码包包含课程、Notebook、离线阅读页和小型数据；不包含 Python 运行时、.venv、190个安装包或预训练大权重。第一次需要联网准备；准备完成后，案例运行可以离线。

本发布版验证目标是 Windows x64、Python 3.12、CPU。其他系统、ARM、GPU环境未经验证，不能直接套用这份锁文件宣称兼容。深度学习案例建议有16 GB内存，模型下载和离线备份还需额外磁盘空间。

1. 安装 Python 3.12 x64

从 Python 官方 Windows 下载页选择 Python 3.12 的64位安装程序，安装 pip、venv 和 Python Launcher。不要使用精简的嵌入式包替代完整安装。

在课程根目录打开 PowerShell，核对：

py -3.12 -c "import sys,struct; print(sys.version); print(struct.calcsize('P')*8)"

应显示3.12和64。找不到3.12时，安装器会给出明确提示，不会自行替换系统 Python。

2. 创建课程环境

可以双击 首次安装.cmd，或运行：

py -3.12 tools/setup_environment.py
.venv/Scripts/python.exe tools/self_check.py --core --full-hash

安装器创建课程内的 .venv，按 requirements-lock.txt 的190项精确版本安装，执行 pip check 并绑定课程 Jupyter 内核。已有可用 .venv 会原地补齐锁定版本；不会自动重命名或删除。运行中的 Notebook 请先关闭再安装，以免正在使用的库被更新。

在线安装明确使用 https://pypi.org/simple 和 PyTorch CPU 索引 https://download.pytorch.org/whl/cpu；torch==2.8.0+cpu、torchvision==0.23.0+cpu 不改成CUDA版或最新版本。只安装wheel，不尝试源码编译。命令遵循 pip安装选项；虚拟环境使用 Python venv。

没有 Launcher 但已有合适 Python 时，可显式指定：

& 'C:/Path/To/Python312/python.exe' tools/setup_environment.py --python 'C:/Path/To/Python312/python.exe'

先看计划而不安装可加 --dry-run。环境不完整时安装器保留它并提示使用显式修复流程，不会悄悄移走现有环境。

3. 按需准备预训练模型

全部准备（需要联网）：

.venv/Scripts/python.exe tools/prepare_models.py --all
.venv/Scripts/python.exe tools/self_check.py --full-hash

也可以双击 准备全部模型.cmd，或仅下载即将使用的模型：

.venv/Scripts/python.exe tools/prepare_models.py --list
.venv/Scripts/python.exe tools/prepare_models.py --models minilm,flan-t5-small
.venv/Scripts/python.exe tools/prepare_models.py --models minilm --verify-only
名称 相关案例 大致权重大小
resnet18 B19 图像迁移 47 MB
flan-t5-small B21 Transformer 308 MB
minilm B23 向量检索 91 MB
qwen3-0.6b B24 中文资料问答 1.50 GB
chronos-bolt-tiny B15 时序模型拓展 35 MB

以上为十进制近似权重大小，分词器和配置另占空间。模型固定到随仓库 assets/models/*/SOURCE.json 中的40位提交revision；ResNet18使用固定官方权重文件。每个已有或下载文件都按 model_files.json 的大小和完整SHA256校验。SOURCE.json 是本地溯源元数据，不从模型仓库下载。新文件只有完全下载且校验正确后才替换目标文件；已有错误文件默认保留，可显式使用 --repair 重下。不要自行改成 main、latest 或删除哈希检查。

模型是可选准备项：self_check.py --core 不要求模型存在。只准备一部分模型时，全量自检报告其余缺失是预期行为，相关案例要等对应模型准备后再运行。Hugging Face 的固定revision机制见官方下载说明。模型的许可与用途说明见对应SOURCE和课程第三方声明。

4. 开始学习与记录

安装后使用已有 开始学习.cmd。Notebook 使用课程内核；代码运行时禁止联网，模型缺失会明确报错，不会临时下载或伪造答案。只阅读HTML不需要安装Python。

安装日志位于 reports/setup_environment.json，模型校验记录位于 reports/model_preparation.json，自检结果位于 reports/self_check.json。自检通过不替代全部案例重跑；具体环境的案例结果仍由课程验收工具记录。

完整离线恢复和外部wheelhouse安装见 离线准备指南。
