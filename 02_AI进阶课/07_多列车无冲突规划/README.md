## 方法与检查
## 1. 定义地图、动作和碰撞
坐标是(row,column)元组。车辆到达终点后持续占据终点，必须检查后来到达的车辆。这个约定属于模型，不应藏在动画里。

## 2. 时空A*：同一地点在不同时间是不同状态
约束分两种：时刻t禁止占据某点，或禁止在t-1到t走某条边。到终点时还要检查未来约束。有限时间窗没有找到路径只能报告窗口内未找到。

## 3. 先规划的车占用后续车辆的时空资源
优先规划把已规划路径当成预约表。这通常较快，但车辆次序会影响结果，也可能让后车在当前时间窗内找不到路。

## 4. CBS：发现冲突，再分支限制其中一辆车
高层节点保存每辆车的限制与路径；每次按总路径长度取最便宜节点。冲突产生两个子节点，分别禁止其中一辆车造成该冲突；仅重算受影响车辆。资源上限返回UNKNOWN，不能当成无解。

## 5. 保存逐时刻轨迹并解释目标
本例最小化各车到达时间之和，另报告全部到站时间。时间图的每一行能与碰撞检查器对应；不是仅展示单车路径。

## 常见错误与边界
教学模型不是铁路安全控制系统。各边移动耗时为1，到站后永久占位；CBS的最优性依赖低层最短路、冲突划分和目标定义，有限窗口/节点预算未找到解只能报告UNKNOWN。
