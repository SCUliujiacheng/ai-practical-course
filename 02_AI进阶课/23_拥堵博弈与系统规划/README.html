A23 大家各选最快路，为什么总耗时还偏高？

核心案例：离线可学。 首次先按安装指南配置环境、下载所需模型。准备完成后，输入均从本课程目录读取。外部参考链接不影响本地运行。需要联网的延伸活动见联网拓展清单，可延后学习。

六个团队同时出发，可走容量紧张的捷径或固定耗时的绕行路。分别求个体无单方改进的配置和系统总耗时最低配置。

先修与运行

已完成 AI 基础课；会使用列表、字典、函数和 NumPy。涉及的新结构在本例分步解释。

在课程根目录双击「开始学习.cmd」，进入本文件夹并打开教学讲解。也可以双击本目录「运行案例.cmd」。

  1. 阅读任务，写下输入、输出和你预计的结果。
  2. 打开教学讲解，逐格运行，观察变量和图表。
  3. 对照 solution.py 临摹关键步骤。
  4. 完成动手练习的补全、修改与迁移，再看参考答案。
  5. 检查 outputs，解释方案的适用范围。

方法与检查

1. 耗时依赖同路人数

捷径上n人时每人耗时n，绕行路每人恒为5。每队是一名不可分割参与者；本例是有限原子拥堵博弈。

2. 逐个参与者严格改进

每次只让一名参与者改变，而且只有成本严格下降才行动。有限拥堵博弈的势函数随这种更新下降；同步更新或无差别切换不能套用同一停止论证。

3. 系统优化与均衡分别枚举

6人2条路只有64种配置，用穷举取得系统最优与全部纯均衡。最佳回应稳定只保证个人不愿单独改变，未优化系统总耗时。

4. 输出协调收益和个体代价

统一安排可能使某些参与者比其原来更慢，不能只展示总量。建议提供协调方式或补偿讨论；本例不把协调配置假装成自发均衡。

常见错误与边界

本例有限、原子、不可分割参与者，成本只依赖使用者数量。只对顺序严格改进使用势函数停止论证；其他动态需重新分析。
