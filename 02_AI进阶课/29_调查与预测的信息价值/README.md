## 方法与检查
### 1. 定义状态、动作与损失
状态依次为晴、雨，动作依次为室外、转场。每个格子的损失为元。概率与损失来自本题假设，不能冒充天气机构预报。

### 2. 完美信息给出上界
先观察真实状态再行动的期望损失，不会高于不知道状态时。EVPI是两者差额，调查无论多准确都不应在这个模型下比它更值钱。

### 3. 噪声信号与贝叶斯更新
likelihood[signal,state]表示给定天气状态时出现该信号的概率。列和必须为1。posterior与prior不同，不能把准确率直接当作下雨后验。

### 4. 信息需要改变行动才可能有价值
比较不同购买价格的净收益。只有行动选择、信息可靠性和损失模型都正确时，这个购买上限才成立。

### 保存可核验的证据
把指标写入 JSON，并用本次输出形成有条件的建议。json.dumps 把字典变成文本；不会替你判断方案是否适合现实。

## 常见错误与边界
先验、似然、后验不要混淆。信息价值不是信息准确率；同一信号对不同决策可能价值不同。
