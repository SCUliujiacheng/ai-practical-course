# A12 有降雨风险时，应该提前转场还是等待？

> **核心案例：离线可学。** 首次先按[安装指南](../../安装指南.md)配置环境、下载所需模型。准备完成后，输入均从本课程目录读取。外部参考链接不影响本地运行。需要联网的延伸活动见[联网拓展清单](../../联网拓展清单.md)，可延后学习。

把明确标注的降雨概率情景转成行动：户外、立即室内、等待一个有噪声信号再决定。使用贝叶斯更新与决策树计算预期损失，不把温度预测当降雨概率。

## 方法与检查
## 1. 列出天气状态与损失表
仅两种状态：下雨与不下雨。户外遇雨损失 12000，立即转场成本 3000。概率 0.35 是假设，不是查询到的天气预报；每项成本也都是教学单位。

## 2. 等待带来信息也带来代价
湿信号在下雨时出现概率为 sensitivity，在晴天时误报概率为 false_positive。先算信号概率，再用贝叶斯公式算后验；后验必须落在 0—1，不应直接把 0.8 当作下雨概率。

## 3. 从决策树末端往前计算
观察信号后，在户外与延迟转场之间选损失较低者，再按信号概率加权，最后加等待成本。立即转场阈值为 3000/12000=0.25，但加入等待选项后还要比较第三条曲线。

## 4. 交付规则与改变建议的条件
输出当前推荐、每个信号后的动作和全概率范围的决策曲线。风险厌恶、场地容量和极端损失尚未建模；如果等待会失去室内场地，应修改树而非继续使用旧公式。

## 常见错误与边界
所有降雨概率与成本是标明的假设，不能转述为当前城市真实预报。贝叶斯更新依赖信号质量已知，现实中需要校准资料。
