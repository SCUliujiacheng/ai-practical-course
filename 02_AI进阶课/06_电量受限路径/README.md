# A06 最快路线超出电量时，怎样重新规划？

> **核心案例：离线可学。** 首次先按[安装指南](../../安装指南.md)配置环境、下载所需模型。准备完成后，输入均从本课程目录读取。外部参考链接不影响本地运行。需要联网的延伸活动见[联网拓展清单](../../联网拓展清单.md)，可延后学习。

## 方法与检查
## 1. 一条边包含两个不同维度
字典中每个地点映射到邻接道路列表。时间是目标，电量是硬限制，两者不混成一个没有单位解释的分数。

## 2. 扩展状态：位置相同，剩余电量不同
状态用元组(position,remaining)表示，可作字典键。优先队列按累计时间弹出；此处用启发式为0的Dijkstra确保容易检查。保留路径便于初学者观察。

## 3. 用原始道路独立验证
重新累计每条边的时间与电量；不相信搜索函数自行声称合法。小图再枚举所有简单路径，核对目标代价。正耗时和正耗电使绕圈不能改善本题目标。

## 4. 区分不可行基线与有效方案
无电量限制的最快路线只是说明冲突，不能当作可执行推荐。结果表显式标记可行性。

## 常见错误与边界
电量离散且只减少，无充电、再生制动或不确定耗电。路径上的电量是硬约束；扩展状态数量随电量精度增加。
