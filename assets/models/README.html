模型来源、固定版本与下载

本公开仓库不上传预训练权重或课程训练后的权重。此目录保留 SOURCE.json 来源记录，以及已有的上游许可文件；实际权重、配置和分词器文件需在首次准备时从上游下载。准备完成后，案例可从本地读取。依赖安装见 安装指南，完整离线准备步骤见 离线准备指南。

准备入口

在已安装课程依赖的仓库根目录执行以下联网准备命令（Windows）：

.venv/Scripts/python.exe tools/prepare_models.py --all

脚本入口为 tools/prepare_models.py。不要为离线复现擅自把固定版本改成上游最新版本；更换版本后需重新记录来源、哈希并重新验收相关案例。仓库根目录 model_files.json 记录本课程所用文件的预期路径、大小与 SHA-256；它列出了需要准备的文件，不表示 Git 中包含权重。
